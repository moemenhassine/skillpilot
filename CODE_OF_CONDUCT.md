# Code of Conduct

SkillPilot adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. All contributors and maintainers are expected to follow it in every project space, including issues, pull requests, and discussions.

In short: be respectful and constructive, assume good faith, and do not harass, demean, or exclude anyone.

## Reporting

> **Before publication:** the maintainer must add a real, monitored contact for conduct reports here. No address has been invented. See `docs/release-checklist.md`.

Reports will be handled confidentially. Maintainers who do not follow the code of conduct may face the consequences described in the Contributor Covenant's enforcement guidelines.
